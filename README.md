# uBlock YouTube Shorts Filter List

This is a fork of Gijsdev's [Hide YouTube Shorts List](https://github.com/gijsdev/ublock-hide-yt-shorts), but with  updated filters and fixes, especially for mobile.
This is a filter list for [uBlock Origin](https://github.com/gorhill/uBlock) that hides all traces of YouTube Shorts, except under YouTube's History tab.



## Installation

- Open uBlock Origin and navigate to: `Dashboard > Filter lists`
- Scroll down and paste the following  into the `Import...` field.

```bash
https://raw.githubusercontent.com/Harren06/ublock-yt-shorts/main/list.txt
```
- Click `Apply changes` and refresh YouTube.
